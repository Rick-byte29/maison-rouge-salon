# Javed Habib Salon Website

A long-form, mobile-first high-end salon landing page concept for Bongaigaon, Assam.

## Included
- Deep red + white visual system
- Playfair Display + Roboto
- 2-second animated scissors loader
- Real salon/haircut photography via Unsplash URLs
- Responsive mobile navigation
- Animated scroll reveals, marquee, parallax and counters
- Services / pricing / gallery / sample testimonials / contact sections
- Google Maps embed targeting Bongaigaon, Assam
- Sticky WhatsApp booking button for +91 91010 35255

## Run
Open `index.html` directly, or serve this folder with any static server.

## Before launch
Replace the concept brand name, exact street address, operating hours, illustrative pricing and sample testimonials with verified business information.
