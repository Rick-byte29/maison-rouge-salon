# Javed Habib — Premium Salon Demo

A long-form, mobile-first premium salon concept for Bongaigaon, Assam.

## Experience
- Deep red + white editorial visual system
- Playfair Display + Roboto typography
- 2-second scissors loading sequence
- Film-grain / parallax hero treatment
- Scroll reveal choreography, marquee, counters and micro-interactions
- Fine-pointer custom cursor, magnetic buttons and subtle tilt
- Fully responsive mobile layout with persistent booking bar

## Conversion & booking
- 4-step appointment concierge
- Service selection
- Stylist preference
- Preferred date/time
- Name, phone and notes
- WhatsApp handoff to +91 91010 35255
- Expandable desktop Salon Concierge
- Sticky mobile call + booking controls

## Content
- Consultation-led brand story
- Interactive service detail modals
- Demo stylist profiles
- Interactive before/after comparison
- Men's grooming campaign
- Bridal / occasion campaign
- Hair-care ritual section
- Filterable work gallery
- Sample demo testimonials
- FAQ
- General Bongaigaon Google Maps embed

## Local discovery
- Meta description and social sharing metadata
- HairSalon JSON-LD structured data
- Phone, hours, location and directions links
- JH favicon / monogram

## Important demo notes
This is a demo project. Stylist profiles, service prices, operating hours, testimonials and some brand copy are illustrative. The current map points to Bongaigaon generally. Before a real launch, replace sample information with verified branch details and use approved brand/logo assets and consented salon photography.
